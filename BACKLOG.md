# Бэклог задач: Рефакторинг UI/UX тренажера Polski Helper

Статус рефакторинга: **В процессе**  
Целевой дизайн-код: **Developer-grade (shadcn/ui, Linear, Raycast, Vercel)**  
Палитра: **Neutral Zinc / Slate + Carmine (Rose) Accent**  
Темы: **Dark & Light**

---

## Задачи

- [x] **0. Инициализация бэклога проекта**
  - Создание `BACKLOG.md` со структурой задач и требованиями рефакторинга.

- [ ] **1. Система тем (Light/Dark) и токены Tailwind**
  - Поддержка `class="dark"` на `<html>`.
  - Утилита/хук переключения темы с сохранением в `localStorage` (default: dark).
  - Настройка чистой палитры (Zinc/Slate, отсутствие дефолтного синего, сдержанный карминовый rose-акцент, пастельные мнемонические цвета для родов ten/ta/to).

- [ ] **2. Полный дроп статистики, геймификации и звуков**
  - Удаление всех стриков (огонь, дни, серии побед, кубки).
  - Удаление счетчиков ответов, процентов точности и сброса статистики.
  - Удаление Web Audio API звуков, кнопки отключения звука и конфетти.
  - Очистка типов и утилит `src/utils/storage.ts`, `src/utils/audio.ts`, `src/utils/confetti.ts`.

- [ ] **3. Минималистичный Header и брендинг**
  - Только название «Polski Helper» (`font-semibold`, 15–16px) слева.
  - Переключатель темы (иконка Lucide `Sun` / `Moon`, stroke 1.5–1.75px) справа.
  - Удаление флагов, вторичных бейджей («ТРЕНАЖЕР», «Грамматика и окончания»).

- [ ] **4. Рефакторинг Главного меню (Главного экрана)**
  - Замена многословных текстов на лаконичный заголовок h1 («Грамматика»).
  - Карточки модулей без визуального шума.
  - Вынос кнопки теории в правый верхний угол шапки карточки: компактная кнопка `[ Правило ]` с иконкой `BookOpen`.
  - Пункты выбора режимов в виде чистого плоского списка строк:
    * Заголовок пункта (`font-medium`).
    * Сабтайтл в одну строку с практическим примером (`text-xs font-mono text-zinc-500`, напр. `okno → okna`).
    * Минималистичная стрелка справа (`ChevronRight`).
  - Полное удаление спойлеров правил и чипсов с окончаниями из кнопок меню.
  - Полный отказ от эмодзи.

- [ ] **5. Рефакторинг экранов тренировки (Интерактив)**
  - Слово для проверки: чистый шрифт, `font-semibold` (вес 600), умеренный размер, правильный kerning.
  - Варианты ответа в нейтральном стиле shadcn (`bg-white dark:bg-zinc-900 border-zinc-200 dark:border-zinc-800`).
  - Хоткеи 1, 2, 3... как аккуратные Linear-style `<kbd>`-бейджи в правом верхнем углу кнопки.
  - Деликатная обратная связь при ответе: акцентный border (`border-emerald-500` / `border-rose-500`) и тонкий тинт фона (`bg-emerald-50 dark:bg-emerald-950/20`), без ядовитых заливок.
  - Разбор ошибок в строгом Callout-блоке без эмодзи.
  - Сдержанные пастельные мнемонические цвета для рода: мужской (индиго/slate), женский (роза/коралл), средний (песочный янтарь).

- [ ] **6. Рефакторинг справочника и правил (Fullscreen Rules)**
  - Удаление серых рамок-пилюль с каждого слова в примерах (чистый список или 2-3 колоночная сетка).
  - Блоки исключений («Важно:» / «Помните:») — строгие Callout-блоки с `border-l-2`.
  - Селектор Кратко / Подробно в стиле shadcn tabs/segmented control.
  - Полный отказ от эмодзи и цветных кружочков.

- [ ] **7. Финальная верификация, сборка и проверка**
  - Проверка сборки `npm run build`.
  - Проверка работы в светлой и тёмной темах.
  - Деплой на GitHub Pages и отчет.

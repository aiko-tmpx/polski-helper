## Новый модуль: «Словарь и интервальное повторение» (Vocabulary & SRS)

Статус: **В проектировании**  
Бэкенд: **Supabase (PostgreSQL + Auth + Row Level Security)**  
Методика обучения: **Spaced Repetition System (SRS, алгоритм Anki / SM-2)**

### Задачи:

- [ ] **8. База данных Supabase и схема безопасности (Data Layer)**
  - Создание таблицы `user_words`:
    - `id` (uuid, primary key)
    - `user_id` (uuid, references `auth.users`)
    - `word` (text, польское слово)
    - `translation` (text, русский перевод)
    - `notes` (text, примеры/заметки, optional)
    - `interval_days` (integer, default 0)
    - `repetition_count` (integer, default 0)
    - `ease_factor` (numeric, default 2.5)
    - `next_review_at` (timestamptz, default now())
    - `created_at` (timestamptz, default now())
  - Индексы по `(user_id, next_review_at)` для мгновенной выборки очереди на сегодня.
  - Политики Row Level Security (RLS): полная изоляция данных — пользователь может читать, добавлять, обновлять и удалять только свои строки (`auth.uid() = user_id`).

- [ ] **9. Supabase Client & Простая авторизация (Auth UI)**
  - Установка `@supabase/supabase-js`.
  - Файл конфигурации `src/utils/supabase.ts` с переменными окружения `.env` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`).
  - Минималистичная форма входа и регистрации (Email + Пароль) в шапке / модалке (стиль shadcn/Linear).
  - Управление состоянием сессии пользователя (`user`, `session`).

- [ ] **10. Массовый импорт и управление словарем (Dictionary & Bulk Import)**
  - Модальное окно «Импорт слов»:
    - Поддержка чистого JSON: `[{"word": "...", "translation": "..."}]`.
    - Поддержка вставки простого текста / TSV: строки вида `mieszkać - жить` или `mieszkać;жить` (копипаст из ChatGPT / Excel).
    - Автоматический парсинг, валидация и предпросмотр перед сохранением («Найдено 300 слов, 0 дубликатов»).
    - Пакетная вставка (Batch insert) в Supabase.
  - Экран личного словаря: список добавленных слов, поиск, пагинация/виртуализация, удаление и редактирование слов.

- [ ] **11. Тренажер интервального повторения (SRS Flashcards Trainer)**
  - Выборка очереди карточек на сегодня: `next_review_at <= NOW()`.
  - Механика карточек (Anki Flip Card):
    - Лицевая сторона: польское слово крупно + кнопка озвучки (TTS).
    - Оборот (по Пробелу или клику): русский перевод, заметки.
    - Оценка знания с клавиатуры (хоткеи 1, 2, 3, 4):
      - `[1] Забыл` (интервал сбрасывается в 0, повтор сегодня).
      - `[2] Трудно` (интервал 1 день).
      - `[3] Помню` (интервал растет: 1 → 3 → 7 → 16 → 35 дней).
      - `[4] Легко` (интервал растет с бонусом).
  - Сдержанная анимация переворота и чистый developer-grade счетчик оставшихся карточек.

- [ ] **12. Интеграция в Главное меню и верификация**
  - Раздел «Мой словарь» в главном меню с индикатором «На сегодня: X слов».
  - Полное тестирование флоу: регистрация → импорт 300 слов → тренировка карточек → обновление дат повторения в Supabase.
